# portal-web

Фронтенд корпоративного мессенджера (чаты, контакты, звонки, профиль) поверх Matrix (matrix-js-sdk), встроенного под путём `/app/` на сервере видеоконференций Jitsi. Контекст и вся история решений: см. основной README и статью в корне репозитория.

Пересобирается с нуля по детально задокументированному поведению, исходники были потеряны при перезагрузке рабочей машины (никогда не коммитились в git, лежали только во временной рабочей папке).

Домены и название компании в этой копии анонимизированы, см. `src/config/branding.ts`.

## Разработка

```bash
npm install
npm run dev     # http://localhost:5173/app/
npm run build   # dist/
npm run lint
```

Без реального бэкенда (`GET /app/api/session`) приложение показывает экран «Не удалось подключиться» вместо переписки, это ожидаемо вне полноценного дев-окружения с локальным Matrix-сервером.

## Деплой

Собранный `dist/` заливается на прод поверх `/opt/portal-web/dist` (см. `portal-web/server.mjs`, статика читается с диска на каждый запрос, перезапуск сервиса не нужен). Деплой это отдельный явный шаг после полного прохождения всех этапов и smoke-теста, не автоматический.
